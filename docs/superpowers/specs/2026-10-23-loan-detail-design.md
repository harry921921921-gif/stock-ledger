# 借款值不值得：資金來源頁的獲利判斷

2026-10-23 · 使用者已確認：賺贏利息就算符合預期；另外加買進紀錄

## 1. 目的

使用者要在資金來源頁一眼看出：**這筆借款拿去投資，賺的有沒有符合預期**。
股票頁維持券商的做法（平均成本法），不改（2026-10-23 使用者決定）。

spec 第 3 節第 4 頁已經列了「借來的錢值不值得（投資賺到 vs 付出利息、利差）」，這次把它做出來。

## 2. 畫面（每張借款卡片，放在「借款淨賺」那一區）

| 項目 | 算法 |
| --- | --- |
| 投資賺到 | 這筆借款買的股票：帳面損益 ＋ 已實現損益 ＋ 分到的配息（沿用 DR-045 的股數算法） |
| 已付利息 | 沒作廢的「借款利息」合計 |
| 借款淨賺 | 投資賺到 − 已付利息（現有的數字） |
| 投資報酬率 | 投資賺到 ÷ 借款出的錢（目前還在股票裡的借款成本），HALF_UP 到 0.01% |
| 判斷 | 淨賺 ≥ 0 顯示綠色「賺贏利息」；< 0 顯示紅色「還沒賺贏利息」；這筆借款沒買股票顯示「還沒拿去投資」 |

卡片上原本的「借來的錢現在在哪」（每檔股票與金額）保留。

### 2.1 買進紀錄（2026-10-23 使用者追加）

每一筆用到這筆借款的期初持股或買進一列：日期（點了到那筆交易的修改頁）、股票代號（滑鼠移上去顯示名稱）、股數、買價（期初持股是含手續費的平均成本）、借款出的錢。新的在前，作廢的不列。
只記「買的時候」的資料；現在賺賠多少看上面的合計（同一檔用平均成本，不拆每一批）。

## 3. 計算放在哪裡

- 投資報酬率放進 `StockMetricsCalculator`（純 Java、單元測試）。
- 其餘數字 `LoanService.fundingView` 已經有，只是拆開顯示；模板只顯示，不計算。
- 不需要新的 migration。

## 4. 不做的事

- 不做每一批各自的損益、不改平均成本法（股票頁照券商的做法）。
- 不做年化報酬率（持有期間不同，年化容易誤導；之後需要再加）。
