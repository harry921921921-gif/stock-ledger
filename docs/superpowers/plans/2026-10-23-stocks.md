# 階段四：股票 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. 使用者授權自主進行（2026-10-23 睡前）：每個 Task 先寫測試再實作、opus 審查；**不 commit、不 push**；新 migration 不套用到使用者的 Docker 資料庫（驗收用另開的測試資料庫）。

**Goal：** 股票持股、交易（期初、買、賣、配股）、配息入帳、自動記交割戶現金異動、資金來源標記、報酬率、證交所股價與除權息、質押維持率。

**Spec：** `docs/superpowers/specs/2026-10-23-stocks-design.md`；`docs/spec.md` v1.7 第 3、4.1、4.2、4.4、4.5、4.7、5.1～5.6、6、7.1 節。

## Global Constraints
- 金額 `BigDecimal`；手續費、證交稅 `DOWN`；二代健保 `HALF_UP`；比例 HALF_UP 到 0.01%；中間值 10 位。
- 股數 `BIGINT`（Java `long`）；股價 `DECIMAL(12,4)`；金額 `DECIMAL(19,4)` 整數元。
- 費率只從 RateSetting 依交易日取得。
- 個人資料查詢帶 `CurrentUser.id()`；股票、股價、除權息、更新紀錄是共用資料。
- 新 migration：`V10__create_stock.sql`。

## Tasks
1. **Calculator**：FeeCalculator、HoldingCalculator、SourceTagCalculator、DividendCalculator、MaintenanceCalculator（含報酬率）。純 Java＋單元測試（手算數字）。
2. **V10 與 Entity**：stock、stock_price、dividend、price_update_log、trade、trade_revision、source_allocation、pledge_collateral；cash_movement 加 trade_id、stock_id、nhi_amount 與三種類型；rate kinds 維持率門檻。Schema 測試。
3. **證交所資料**：`TwseClient`（RestClient）、`MarketDataService`（解析民國日期、新增或更新、紀錄、啟動與排程）。用樣本 JSON 測解析，用假 client 測服務。
4. **TradeService**：新增四種交易與配息入帳、自動現金異動、資金來源分攤與檢查、修改與作廢（寫修改紀錄）、持股與報酬的畫面資料。
5. **資金來源整合**：尚未投入、借款淨賺、擔保股票與維持率。
6. **畫面**：股票頁、交易表單、賣出、配息、擔保股票；側欄；全部異動頁的交易連結。
7. **審查、測試資料庫驗收、整理問題與 commit 建議。**
